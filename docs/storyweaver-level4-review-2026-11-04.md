## 入选书做了哪些修订

每本的 `data/storyweaver/<id>.json` 保存 `originalText`、`text`、逐项 `textEdits`、原版署名、逐图版权、来源级别、图片SHA256及 `editorialReview.factChecks`。所有原图均保持字节不变；没有把英文图重画成中文，也未生成故事录音。

- **拾金不昧**：对照英文修正“50、100、150、200兰特”的点数误译，整理时间、量词和标点；将“像贝卡一样丑陋”明确为“不诚实的事”，落在行为上；恢复原作最后“像个小英雄”的漏译。保留捡到钱、犹豫、归还、失主担心挨饿的完整情节。
- **阿利雅的飞行梦**：统一标题与正文三种主人公译名；将Chawla的252圈明确为首次航天任务，把broke apart修正为解体；区分三位战斗机飞行员与空军整体救灾职责。末页原作“点击另一个版本”改成普通版本提示，避免死链接指令。
- **谁偷走了巴伊亚的笑容**：修正“想开心起来”被译成“已经很开心”、人物台词误译和怪物名不一致；局部重写书末科普说明，区分普通伤心和持续困扰，保留可信任的大人和专业帮助，不把抑郁症等同于脑外伤，也不提示儿童自行吃药。保留家人前半不理解、后半学习陪伴的叙事，以及最后一页无字图。
- **火星之旅**：原作本身的“四种仪器”按ISRO核对为五种；纠正dish被译成“菜”、轨道图例语序和印度数字分组；明确投石索只是比喻，发动机提供加速，地球引力不会突然消失；把“今天仍在传照片”更新为2022年结束任务；区分近地轨道载人计划与载人火星愿望，移除相对年份预测；局部校订引力、质量和运动变化的解释。保留原作任务顺序和图示，不将校订版冒充未修改的原版。

最后两本含资料页的内容校订超过标点整理，阅读页“作者与来源”说明已明确修改，原文可逐项追溯。现有文字仍不是教师、天文学家或心理专业人员完整审定的教材。

## 本地验证与维护

复用已有的StoryWeaver 1～4级数据模型与阅读器，没有新增等级体系、录音能力或整书TTS。4级筛选、书卡标签和离线分组由 `sourceLevel` 自动生成，未为本轮四本书写死界面分支。

后续校订先改审核清单 `data/storyweaver/<id>.json`，再运行 `npm run assets:storyweaver` 生成 `data/books.json` 和 `assets/sources.json`；只改生成后的书目会被构建一致性检查拦住。图书简介和亲子提问维护在 `data/book-notes.json`。

验证通过：

- `npm test`：41项全量单元/内容检查通过，含现有素材的完整音频解码检查；最终文字校订后追加8项导入与构建边界专项通过。
- `npm run build`：80本、1686个文件、225.0 MiB，最终内容版本为 `4ed8d909aa58e2c1`。
- Chromium + WebKit两轮共覆盖42个不同浏览器场景（运行数26+28，包含重复回归）：4本新增书全部77页按顺序渲染、主动完成、320/390px手机首尾页、来源分级隔离、触摸尺寸、原无字/纯文字/图上编号兼容，以及子路径下4级整组下载后断网逐本首尾页阅读。最后一处火星文字语序校订后，其4个相关场景再次通过。
- 4本全部正文经OpenCC复核，无需继续简体化的差异；每条校订后的文字均能在对应页面中找到。构建检查逐张原图哈希与审核清单、生成书目及来源记录一致。
- 原76本书的运行时内容与本轮开始时一致；审核收尾时暂存区为空，当时未执行提交、推送或发布，后续源码提交状态以Git记录为准。工作区同时存在的设备声音调整由另一轮任务处理，本轮未修改其实现。
- 已在用户Chrome中查看本地80本书库、4级四本的封面及实际阅读页，保留原有阅读记录。没有清空浏览器数据。

已修复的是译名、错字、误译和可核实的局部事实；本轮不额外增加书架控件。是否适合孩子的阅读时机、怪物形象和人物生平话题，仍需家长试读判断。真实iPad的字号、触摸、设备字音和离线共读不能由浏览器模拟替代。
