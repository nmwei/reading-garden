# 阅读小花园 · Reading Garden

面向儿童的中文绘本阅读与识字网站，作为 `../abc-garden` 的同级独立项目。

## 当前状态

2026-11-03：当前实现包含独立书库、最近想读小书架、原版故事首屏、手机书卡优化、拼音听读、家长更新工具、40本完整中文书库、分级筛选、选择性离线下载及差异发布入口。27项单元/内容检查及76项Chromium/WebKit浏览器场景已完成验证（全量75项通过，修正测试同步后相关14项回归通过）。主站为GitHub Pages，发布结果以Git提交和线上版本为准。孩子尚未学拼音，拼音作为独立内容；正文不加拼音。详细边界见 [验收记录](docs/acceptance.md)。

本轮源码包含：StoryWeaver《绘画游戏》完整12页，当前本地共41本；新增来源分级筛选及书卡标签排版，构建、30项单元/内容检查和94项Chromium/WebKit浏览器场景通过。本轮只提交源码，不推送、不发布；真实iPad仍需验收。详见下方“StoryWeaver 单本试读”。

## 第一版功能

- **故事书架**：Storybooks Canada简体中文书库全部40本，共420页正文、460张封面/插图和420段逐页普通话录音。保留原站1～5级，分别15/11/8/4/2本；按级别和主题组合筛选。每本保留文字作者、绘者、译者、朗读者及各自来源记录。
- **最近想读**：首页复用`bfbb045`版本的原始故事首屏（两行标题、相框封面、背景装饰及原响应式样式），下方展示最多6本的小书架；书库独立为`#/library`，保留40本故事、最近读过及分级/主题筛选。书架和书库共用相同书卡，显示封面、级别、书名、进度和阅读入口；未选书可放到小书架，已选书在两处都可直接移出。没有整理或撤销状态，移出后可从书库重新加入，阅读位置、生字和读完记录保留。PC/iPad每行3本，手机每行2本；手机卡片底部将阅读与加入/移出合为一行，进度文案精简并使用12px字号，长书名完整换行；空书架引导选书，读完可从第一页重读并恢复重读位置。
- **阅读**：大图翻页、原句点播、响应式正文排版、返回书架及阅读位置恢复。正文不显示拼音。点字求助提示仅在本机首次阅读时显示，后续翻页、换书和刷新不重复。
- **生字篮**：点击汉字查看当前语境，主操作听所选字音，下方可听原句；收藏按钮支持加入、移出和加回，阅读页与生字篮使用同一弹窗。常见词提供项目编写的简短解释；单字读音调用设备中文声音，无中文声音时提示并回退听原句。
- **拼音小课堂**：从导航“学拼音”独立进入；书架底部不再重复放置拼音宣传卡片。包含24个韵母、21个声母、拼写字母y/w、16个整体认读音节和按类型分行的20组四声。63项认识内容与80段四声均可播放；其中ong采用用户试听选定并确认授权的ChinaHelp独立录音，其余使用CLI。三页选择卡统一28px，点字母即播，均有“顺序听”及暂停/继续/停止；认读连播额外等待0.3秒，四声0.2秒。听音练习直接多选声母/韵母/整体认读，保存范围、每题固定三个选项；多类轮换出题，每题选项保持同类并按录音去重。
- **家长小角**：长按1秒确认进入（含直接链接及刷新），离开后需重新确认。中文设备声音选择、按书/级别/拼音/全部范围的离线下载和本机记录清理；应用更新默认收起，只保留检查更新和重新加载页面；重新获取资源放在离线区。来源区默认收起，只汇总绘本平台/许可及CLI、ChinaHelp两套拼音来源；逐本署名保留在阅读页，不提供直接打开JSON的家长入口。
- **离线**：HTTPS或localhost下，完整资源约88.1 MiB（92.4 MB），可按书或级别下载；阅读页也可“下载这本书”。最多4路下载，失败保留已完成项以便续传。基础缓存保留书目和全部封面，已下载的正文图音可断网使用。普通局域网HTTP不支持Service Worker；首次打开需要联网。

## 开发与预览

需要 Node.js 20+。首次获取依赖：

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:4178/`。源文件修改后重新执行 `npm run build` 并刷新；开发服务读取 `dist/`，不提供源码热更新。正式站新版安装后等待家长点击“应用更新 → 重新加载页面”，再接管并清理旧缓存；安装时会校验并复用旧缓存中仍在本版清单里的图音，不重新下载未变化素材；检查更新不会提前切换版本。本地localhost预览沿用ABC Garden的自动接管方式，初次从旧缓存迁移可能需要刷新两次。本地预览需保持`npm run dev`运行，服务停止时浏览器可能仍显示离线旧页面。浏览器学习记录不清除。

```sh
npm test                     # 状态、内容完整性与音频解码检查，需要ffprobe
npx playwright install chromium webkit
npm run build
npm run test:e2e             # iPad Chromium/WebKit，横竖屏/手机、子路径和离线
```

`dist/` 可部署到静态HTTPS服务器，支持项目子目录。主站已迁移到 [GitHub Pages](https://nmwei.github.io/reading-garden/)，源码位于 [nmwei/reading-garden](https://github.com/nmwei/reading-garden)。`main` 保存源码，`gh-pages` 保存构建产物，Pages选择 `Deploy from a branch → gh-pages → /(root)`。

本仓库提供独立的差异发布入口，从本项目目录运行：

```sh
npm run deploy
```

脚本要求位于 `main`、源码已提交且工作区干净，再重新构建，并将源码和网站快照原子推送到 `main` / `gh-pages`。临时仓库复用本机Git对象，只上传远端缺少的对象；站点快照使用自己的临时索引，不操作本项目暂存区。实现沿用ABC Garden的发布逻辑，本仓库可独立运行，不依赖同级目录。

此前3本书规模的全量构建实测约0.15～0.21秒（3次本机测量，中位数0.157秒）；当前40本已完成完整构建与素材校验，尚未专门评测构建耗时，暂不引入增量构建缓存。差异上传已启用；GitHub Pages云端排队不属于本地脚本的加速范围。

旧 [Sites预览站](https://reading-garden.adroitcoati1.chatgpt.site) 仍保留，`.openai/hosting.json` 仅用于保留旧站身份，不再作为默认发布目标。新旧站域名不同，本机阅读记录和生字篮不会自动迁移；本次未清理旧站数据。

| 文件 | 职责 |
| --- | --- |
| `data/book-notes.json` | 本项目编写的主题、简介、关键词和亲子提问；独立保存，重新导入不会丢失 |
| `data/books.json` | 书架资料、原站分级`sourceLevel`、每页文字、插图、音频和作者署名 |
| `app/reading-levels.js`、`scripts/storybook-metadata.mjs` | 来源分级标签及导入解析；明确记录分级体系，不按年龄或识字量推定级别 |
| `app/main.js` | 书架、阅读、生字篮、拼音与家长页面及交互 |
| `app/core.js` | 本机记录校验（含独立的`readingList`及6本上限）、路由边界、语境词解释、练习选项 |
| `app/pinyin.js` | `FINAL_GROUPS`等定义内容；`TONE_GROUPS`定义分类、生成`TONE_BASES`四声音节，`toneExamples`生成4张卡片；`nextPracticeCategory`/`practicePool`控制多选范围、轮换及同类候选；`PINYIN_RECORDINGS`自动生成；目前不提供家长页面的课程配置 |
| `app/audio.js` | 共享播放器、取消、防重叠、可暂停的顺序播放和设备中文声音；`main.js`的`startPinyinSequence`设置额外等待 |
| `app/parent-gate.js` | 复用ABC Garden的1秒长按逻辑，释放/移出/失焦/后台取消，支持键盘；`main.js`同时守住路由入口 |
| `app/library.js`、`app/offline.js`、`sw.js` | 下载范围、4路并发与失败收尾、图音哈希校验、跨版本复用及更新失败清理；保留音频Range响应 |
| `assets/sources.json` | 逐本/逐录音授权、作者、修改说明、来源与SHA256 |
| `scripts/import-assets.mjs` | 读取官方中文目录及逐本HTML，从固定哈希的官方ZIP导入图音；独立核对文字/图片/录音许可；需要curl、unzip |
| `scripts/import-pinyin.mjs` | 单独导入CLI原始MP3、校验时长并更新来源记录，不重新下载绘本 |
| `scripts/build.mjs` | 核对授权素材哈希、生成静态站与离线版本清单 |
| `scripts/publish.mjs`、`scripts/publish-tree.mjs` | 独立差异发布、批量快照、临时索引及源码/站点原子推送；`npm run deploy`调用 |

新增绘本应同时维护书目、逐页素材及来源记录；`sourceLevel`保存原站体系（`system`）和数值（`value`），与授权记录同步。导入从原站书末Level元数据读取，不按CSS类名或页数推测；缺失或不支持的级别会报错，需核对后导入。当前支持Storybooks Canada 1～5级，新增平台须单独核对其分级含义。

正文统一采用30～38px的响应式字号，配合行距及阅读宽度；手机和iPad竖屏上下排版，横屏与电脑左右排版。旧版字号偏好自动忽略，不删除阅读进度、生字篮或其他设置。

构建会拒绝缺失或与来源记录哈希不一致的素材。重新导入绘本使用 `npm run assets:import`；`npm run assets:import -- --refresh`会刷新目录和逐本元数据。缓存保存在忽略目录 `.asset-cache/storybooks/`，图音ZIP锁定版本与SHA256，变化时须先核对再更新。绘本导入保留现有拼音素材及授权，不重新抓取拼音。

## 验证和内容边界

- 内容沿用原站完整中文书库，尚未对孩子逐本做实际阅读难度验证。分级沿用[Storybooks Canada原站标准](https://www.storybookscanada.ca/about/faq/#how-are-reading-levels-assigned-within-storybooks-canada)，主要描述文本长短与句段结构；不代表中文识字量、年龄或孩子已经达到的能力。
- 绘本文字、插图和原有录音保持原样；简介、亲子提问、词语解释和界面为本项目编写。译文、解释及发音未经教师逐条审核。
- 拼音主页以符号和“听读音”为主，不通过例字代替发音。示范音节及声调单独标出：认识拼音的启用示范统一采用第一声（含ē、yū及r/ri的rī）；四声对比仅在专门活动中呈现。声母使用呼读方式示范，如b使用bō，不能当作单独本音；此前ong误配hōng已撤下，目前使用用户试听选定的ChinaHelp独立示范，可点读、连播和出题。i/u/ü等单独成音节时使用yi/wu/yu等完整拼写，保留提示。CLI及ChinaHelp原始MP3均未剪辑、变速或变调。
- 已包含基础符号表及整体认读音节，尚不包含系统拼读课程。按[人教社刊载的教材修订研究](https://www.pep.com.cn/bks/xxyw/jzjd/202512/W020251202580887481487.pdf)，21个声母与拼写字母y/w分开显示；er作为特殊韵母单列，不算复韵母。发音提示由本项目编写，仍需教学反馈。
- “读完”仅由孩子主动点击记录，不代表已经掌握全部生字；翻到最后一页不会自动标记读完。
- 阅读位置、生字篮、读完标记、声音及拼音练习范围保存到本机localStorage。没有账号或跨设备同步；清除浏览器数据会丢失记录。
- 故事和拼音素材可离线播放；单字读音使用设备中文TTS，是否可离线取决于设备声音。没有中文声音时回退听原句。
- 浏览器模拟检查不能替代真实iPad对触摸、横竖屏、系统声音和主屏幕离线使用的验收。

## 完整拼音听读表（2026-11-03，ong修订前记录）
