# 阅读小花园 · Reading Garden

面向儿童的中文绘本阅读与识字网站，作为 `../abc-garden` 的同级独立项目。

## 当前状态

2026-11-03：第一版本地网站已实现；首版7项单元/内容检查、14项浏览器场景通过；录音修订后8项单元/内容检查与4项拼音/离线目标浏览器场景通过，构建通过。用户已授权开始开发，并确认孩子尚未学拼音，拼音作为独立内容。详细边界见 [验收记录](docs/acceptance.md)。

## 第一版功能

- **故事书架**：3本精选绘本，共21页正文；保留原有连续插图和逐页普通话录音，支持按主题筛选。
- **阅读**：大图翻页、原句点播、大字模式、返回书架及阅读位置恢复。正文不显示拼音。
- **生字篮**：点击汉字查看当前语境、听原句、收藏和移出。常见词提供项目编写的简短解释；单独词语可调用设备中文声音。
- **拼音小课堂**：独立入口，包含6个单韵母和ba四声的图文内容；目前仅保留o、u及第二、第四声录音，其余示范音待补充。听音题仅使用仍启用的录音。
- **家长小角**：中文设备声音选择、字号设置、离线包下载、来源署名和本机记录清理。
- **离线**：HTTPS或localhost下，可下载约2.1 MB的完整包；已下载后支持离线阅读和本地录音播放。普通局域网HTTP不支持Service Worker；首次打开需要联网。

## 开发与预览

需要 Node.js 20+。首次获取依赖：

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://localhost:4178/`。源文件修改后重新执行 `npm run build` 并刷新；开发服务读取 `dist/`，不提供源码热更新。新版离线缓存安装后立即接管并清理旧包，以撤回已停用素材；已打开页面的界面需要刷新后更新。旧版首次迁移可能需要刷新两次，浏览器学习记录不清除。

```sh
npm test                     # 状态、内容完整性与音频解码检查，需要ffprobe
npx playwright install chromium webkit
npm run build
npm run test:e2e             # iPad Chromium/WebKit，横竖屏/手机、子路径和离线
```

`dist/` 可部署到静态HTTPS服务器，支持项目子目录。Sites发布配置保存在 `.openai/hosting.json`，站点默认仅所有者可访问；部署版本以Sites发布记录为准。站点地址：[阅读小花园](https://reading-garden.adroitcoati1.chatgpt.site)。

## 维护入口

| 文件 | 职责 |
| --- | --- |
| `data/books.json` | 书架资料、每页文字、插图、音频和作者署名 |
| `app/main.js` | 书架、阅读、生字篮、拼音与家长页面及交互 |
| `app/core.js` | 本机记录校验、路由边界、语境词解释、练习选项 |
| `app/pinyin.js` | `VOWELS`/`TONES`定义教学内容，`PINYIN_RECORDINGS`定义启用录音；目前不提供家长页面的课程配置 |
| `app/audio.js` | 共享播放器、取消、防重叠和设备中文声音 |
| `app/offline.js`、`sw.js` | 离线下载、应用缓存与音频Range响应 |
| `assets/sources.json` | 逐本/逐录音授权、作者、修改说明、来源与SHA256 |
| `scripts/import-assets.mjs` | 从已审核的源站导入素材，需要curl、ffmpeg |
| `scripts/build.mjs` | 核对授权素材哈希、生成静态站与离线版本清单 |

新增绘本应同时维护书目、逐页素材及来源记录，构建会拒绝缺失或与来源记录哈希不一致的素材。重新导入使用 `npm run assets:import`，下载缓存保存在忽略目录 `.asset-cache/`。

## 验证和内容边界

- 现有内容是用于试读的首批样书，尚未对孩子做实际阅读难度验证。
- 绘本文字、插图和原有录音保持原样；简介、亲子提问、词语解释和界面为本项目编写。译文、解释及发音未经教师逐条审核。
- 已启用的拼音录音通过带声调的例字听读，不将例字录音宣称为六个单韵母的纯音录音。i、u、ü的例字分别为“一、屋、鱼”，完整音节写作yī、wū、yú。第四声教学例字用“爸”，录音来源字为同音的“罢”。
- 拼音仅为第一课，尚未包含完整声母、复韵母、鼻韵母、整体认读音节或系统拼读课程。
- “读完”仅由孩子主动点击记录，不代表已经掌握全部生字；翻到最后一页不会自动标记读完。
- 阅读位置、生字篮、读完标记与声音/字号偏好保存到本机localStorage。没有账号或跨设备同步；清除浏览器数据会丢失记录。
- 故事和拼音素材可离线播放；单独词语使用设备中文TTS，是否可离线取决于设备声音。没有中文声音时回退听原句。
- 浏览器模拟检查不能替代真实iPad对触摸、横竖屏、系统声音和主屏幕离线使用的验收。

## 已确认的需求

- 使用者：5岁儿童，目前约认识400个汉字；具体已认识哪些字尚未确定。
- 主要设备：iPad。
- 学习目标：中文认字与阅读。
- 内容偏好：文章、故事，尤其希望有丰富的绘本插图。
- 与现有英语网站同级建立独立项目，便于单独维护。

## 后续可讨论的扩展

- 以图画故事阅读为主，在故事中巩固识字。
- 试读合适后，将书架扩展到10～20本精选绘本。
- 家长可以选择故事并调整阅读范围；不以识字总数直接判定阅读等级。
- 正文保持不加拼音，是否扩充独立拼音课程、添加更多读后练习，结合实际试读决定。
- 普通话多音字、分词、译文自然程度和故事适龄性需要逐篇校对。

- [我喜欢看书](https://www.storybookscanada.ca/stories/zh/0087/)

- o保留Luilui6666的录音；u及第二、第四声保留Yue Tan的录音。保留不等于已经完成教师逐项审核。
- `PINYIN_RECORDINGS`同时约束按钮、播放器、出题、导入和构建，避免只在页面禁用却仍从练习或离线包播放旧音。
- 示例音尚未找到经试听认可的替代版本；目前明确展示“示范音待补充”，不自动用设备TTS替代教学音。
- 拼音内容尚为入门课，未设置完整课程开关；声母、其他韵母、整体认读音节和系统拼读需后续扩充并配套核对录音。
